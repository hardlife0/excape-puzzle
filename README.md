# 룸익스케이프 화이트점 · 데스크퍼즐

2주에 한 번 문제가 바뀌는 손님용 퍼즐 페이지입니다.
문제를 풀면 2층 매장에서 비밀 할인을 받을 수 있는 화면이 열립니다.

**주소** → https://hardlife0.github.io/excape-puzzle/

- `index.html` 파일 하나로 굴러갑니다. 사진·문구·정답검증이 전부 이 안에 들어 있습니다.
- 문제는 한국 시간 기준으로 2주마다 저절로 다음 문제로 넘어갑니다.
- 직원 미리보기: 주소 뒤에 `#p=3` (3회차) 또는 `#p=i` (물고기) 를 붙이세요.

## 고치는 법

이 저장소에는 완성본만 올립니다. 문구·정답·주기를 고치려면
`바탕화면\white-quiz` 폴더에서 `_template.html` 을 고치고

    python build.py

를 돌린 뒤, 새로 만들어진 `index.html` 을 여기에 덮어쓰면 됩니다.

> ⚠ 정답 풀이지 사진(`KakaoTalk_*.jpg`)은 절대 이 저장소에 올리지 마세요.
